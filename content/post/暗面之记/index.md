自读博以来我都觉得自己过着一种淡淡的幸福生活，平淡而稳定。但突然地，就像世界翻到了反面一般，我的情绪，我的视角，我的思维发生了翻天覆地的变化，过去视若幸福的平淡成了痛苦的停滞。这段时间内我的想法每天都在翻天覆地，而正当自己导出了最终的结果，决断迈出新的步伐时，生活又再度翻面，变回了原来和蔼可亲的模样。

这四周里原本埋藏的心病被连锁反应般引爆，又一一痊愈。是激素下去了吗？还是问题解决了呢？还是我放下了呢？我不知道，我只知道这段时间内我的挣扎与迷茫是真实的。

现在回过头看，人甚至无法理解一周之前的自己，但生命的长度不正是这样全新的体验垒起来的吗？我无法否认这不是真实的自己，所以我要记下来。

# 0
读博的第一年是非常惬意的，几乎都在居家做理论，累了就打游戏，也很少被上压力，而进度也在稳步推进，泡温泉般舒适。

但偶尔也会被压抑折磨，我从未谈过恋爱，又长期接触二次元，自然生长了美好而扭曲的幻想。而现实是是空虚的，我没有找到任何能承载这些幻想的人——理应如此，因为我的社交圈小的可怜，正如常见的读博牛马一般。

因此我从理性上排斥这样虚幻的想法，我将目光收回现实，觉得只要找到喜欢的女生就可以大胆前进了，但就是这样的想法也难以如愿。少有社交的我被动等待着，不知道要等多久，但我有的是耐心。

# 1
不知不觉读博就过了一年，我虽然没等到自己喜欢的女生，却社交到了一批好友。其中一个网友也类似我这样的境遇，保持对美好的幻想在现实中沉浮。

而令我羡慕的是，他真的遇到了配得上幻想的女生，美丽、可爱、热烈。这样的女生是他的理想型，也是我的理想型，不过我清楚，互联网上处于光环之中的女生能满足幻想的比比皆是，她们不是我能在现实中触碰到的存在，也不是我想触碰到的存在，因此我从未有过想法。

但是，他有，更令我嫉妒的是，他们的关系在飞速的升温，至少就我所知。我对这样的女生建立了厚实的心之壁，从未有过靠近的想法，对他却毫无防备，于是犯下了致命的错误，代入了他。

他如愿约会，而我的心在下沉，我的压抑又犯了。我意识到之前的消极等待是错误的，既然他能有这样的缘分，我为什么不能有呢？于是我开始悔恨之前荒废的时间，并决定开始社交，但具体怎么社交呢？我不知道。

这就是第一周，这周的末尾，我做了扩列条并发出，妄图扩展社交面。按之前的经验，压抑到这就应该消退了，而我想不到的是，这只是前菜。

# 2
第二周，我开始做实验。

实验是我非常害怕的东西，自己忙了一年的理论，实验经验少得可怜，这个项目只有我在单干，出了问题都没法求助。于是理所当然地，出了问题，我以贫瘠的经验尝试debug，进度甚慢。

在实验台上操作的时候，我不仅为实验苦恼着，也为自己的爱情苦恼着。我一边代入磕着网友的甜果，一边思索自己以后的行动。当然，复刻不来，新加坡不是上海，类似的机会希望渺茫，而另一方面，每段关系都是独一无二的，代入他人企图模仿本来就是愚蠢。迷茫呵、痛苦呵，我也清楚这是愚蠢，只是免不了幻想这样的可能性，也许思索一段时间未果之后，就会醒悟过来吧。

但始料不及，就在又一次约会后，他们的关系戛然而止了，在烟火大会最盛放的时候，夏天猛地结束了。故事突然收尾了，里面有我当旁观者，故事结束的时候，我处于愚蠢的幻想之中，故事不会再书写了，而我也如愿在这个故事里永远保持愚蠢的面目。

我更迷茫了，以至于愤怒的地步，但我无法对别人发怒，一切都是咎由自取。我因为友人的进展被勾起了欲望，那因其失败而平息才是合理的，但这梦太过美妙，我为自己必须醒来而难过，又为自己不愿醒来而愤怒。

话虽如此，我还是缓过来清醒了，剥离了对爱情的幻想之后，我发现自己问题的根源可能是孤独，我在现实友情上的缺失，未必不必爱情上的严重，对爱情的追求或许千难万难，但找几个好朋友还会难吗？

于是在这周的末尾，我决心脱宅，投入一些现充活动寻找朋友。

# 3
又是新的一周，又开启了新一周的实验。

实验中的问题依旧，即使尽力解决了几个问题，前方依然有海量的问题。论文中频繁提到的现象，也是我预测会有的成果，没有观察到。生活在我眼中已经是不可名状的样子，工作终究也没有放过我，两边的世界都在褪色。

借来的实验室冷冷清清，没有一个熟人，一个人整日与机器相伴，就这样患上了孤独症。我开始害怕独处，每当难受时就上楼回自己的实验室找人聊天，晚上则是拉人联机游戏。我深刻地意识到，社交扩圈不能再拖了，于是我进行了一些行动，比如买网球拍，却没有约到人学网球，比如约人逛漫展，却因为漫展延期而作罢，比如加了攒局的群，却时间冲突至今未参加。虽然这些尝试没一个成功，至少有在行动，这是对我实在的安慰。

在实验室的独自沉思中，先前埋的雷终于被发现，我终于发觉自己是代入了友人，终于发觉自己虽对对方女生毫无想法，却借由代入，捏了一个符合自己所有幻想的幻象，正如小时候对白月光那样。我懊悔自己的愚蠢，懊悔自己的天真与幼稚，但还好还是在挖掘内心的过程中走了出来。我捏碎了心中的幻想，至少是这次的幻想，我明白了所谓的理想型是多么的愚蠢，我要爱具体的人。那么答案还是扩圈，我要见识足够多的人，直到遇到自己感兴趣的女生。

这时的我虽然还是看不清未来，但既然有了明确的行动方针，也不觉得迷茫了。

这周末我去买了网球拍，期待未来的现充生活。

# 4
度日如年一般到了第四周，我已经对之前的思考作了整合，自以为能下结论了，谁知又有了翻新。

我发觉自己之前的问题，对爱情的幻想也好，对友情的渴望也好，对孤独的害怕也好，都是表象，自己真实缺失的是对生活的热情，我找不到自己的热爱之处了。先前喜欢的都在褪色，游戏变得电子阳痿，gal不再有耐心，就连舞萌都显得无趣了。

彷徨多日，我终于触碰到了问题的核心，即自己是空心人这件事。到这，我反而不担心了，因为这是一个已知的问题。我也不急着行动了，因为自己还处于焦虑之中，贸然寻找新的兴趣只会触发自己的厌恶。

工作倒是终于有了起色，先前的问题一个个解决，自己也获得了满意的数据，之前写的论文手稿导师也终于修改，可以准备提交了。我先前的burn out一扫而空，但痊愈过后的心累还是难以消去的，所以我请了假预备下周末回国，这时最能让我放松的我想就是国内的漫展了。

终于是尘埃落定，我可以休息了。

# 后记

不知道是我觉得自己已经想清楚了，还是控制我情绪的激素已经下去了，还是事情已经过去了，前面那些折磨我的、拷问我的、推动我的感情，我已经无法理解了，当时的心境也再回不去了。

这段时间内我对爱情是多么的渴求与迷茫，现在又回到了以前的时候，觉得暂缺也行，反正我不缺这个爱，就算拖到近三十去相亲也无所谓。先前的孤独症也无影无踪，又回到了独处万岁的心态。

我无法理解，但我不能忘记。这是我心中的暗面，即使许久才能窥见到一次，也是我真实的一面。
